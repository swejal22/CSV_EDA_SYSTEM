# Automated EDA System

## Overview
This project implements an automated Exploratory Data Analysis (EDA) system in Python.
Given a dataset, the system generates a concise, human-readable EDA output including:
- Dataset overview and data quality checks
- Descriptive statistics for numeric and categorical variables
- Multiple visualizations
- Key insights and limitations

The system was designed to run end-to-end on multiple datasets.

---

## Features
- Dataset shape, column types, and missing-value summary
- Duplicate and low-information column detection
- Descriptive statistics (mean, median, mode, IQR, outliers)
- Automatic visualizations:
  - Histogram
  - Boxplot
  - Bar chart (categorical or binned numeric)
  - Scatter plot
  - Correlation heatmap
- Human-readable insights and bias/limitation notes
